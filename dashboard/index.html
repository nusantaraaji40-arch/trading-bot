02 // Model Bayesian

Prior (tren + histori) digabung dengan likelihood (harga live + sentimen berita) menjadi posterior — lalu posterior itu yang memutuskan beli atau jeda.

Prior: tren BTC 24 jamNaik
Likelihood: sentimen berita−3 (negatif)
Posterior: keputusanJeda (NO_TRADE)

Berita di sini berfungsi sebagai filter risiko, bukan sinyal beli.
